Once you gain access to PrairieLearn, read the following sections describing first steps for working with its web interface.

Making Your First PrairieLearn Question

Entering an AI Prompt

Log in to the PrairieLearn course site and navigate to your course. Click on “Questions” in the left-hand navigation menu. Then click the “Add questions” drop-down and choose “Generate question with AI”. Enter whatever details of a question you’d like. For a simple first example, you might consider: “Show a randomly generated linear equation and a random x value. Students must enter (short-answer) the resulting y value.” The AI will process for a bit and then generate a question you can try out in the “Preview” tab.

Adjusting the Question with AI

With the initial draft question generated, you can chat with the AI to adjust it as needed. When you are satisfied with the question, click “Finalize question”. Give it a title (student-facing) and a QID (question ID). The QID must be unique within your course. Click “Finalize question” again.

Exploring the Question

Click on the questions tab, and click the link for the question you just made. It will open in the “Preview” tab, where you can try it out again. Click on the “Settings” tab for the question and note what’s available. Also briefly check out the “Files” tab, and you’ll see that there are three files associated with your question:

  • info.json - contains basic settings for your question, in JSON format
  • question.html - defines what the question looks like to students, in HTML format
  • server.py - defines how the question is generated, in Python code

Only minimal JSON and HTML knowledge is needed, if any. For Python, more can be helpful, but you can also manage with little or none if you use AI to help you.

Making Your First Assessment

In PrairieLearn, an “assessment” is a collection of questions that students will answer. There are two types of assessments, “Homework” and “Exam”. The type determines some default settings, but these can be adjusted anytime. When you’re ready to make an exam to be administered in the ETF, you’ll make an assessment of type “Exam” and then follow ETF procedures.

Creating an Empty Assessment

To make your first assessment, click on “Assessments” in the left-hand navigation menu. Then click the “Add assessment” button. Let’s give it the title “Homework 1”, short name “hw1”, set the type to “Homework”, and the “set” to whatever you’d like. (You can also edit the available assessment sets in Course Settings, Assessment Sets.) Press the “Create” button.

Adding Questions to the Assessment

You’ll see your new assessment’s page. There are no questions in it yet, so click “Add questions”. You’ll see “Zone 1”. In the right panel, you can click your question (not the blue underlined link, but the box around the question) to add it to the assessment.

Hit the blue disk icon button (labeled “Save” on hover) to save, and you’ll be back in your Assessment.

Go back to the Questions page and make a few more questions, so that you have a few to try out the assessment functionality with. Then add them to your assessment.

Exploring the Assessment

When looking at your assessment page, you can try it out as a student will see it by clicking on your name in the upper-right corner and choosing “Student view without access restrictions”.

When you’re done exploring it, go back to the regular view (upper-right corner, “Staff view”). Click the other tabs at top to explore what’s possible, such as the “Access” tab, “Files”, “Manual grading”, “Settings”, etc.

Importing Content from Canvas

If you have quizzes on Canvas that you’d like to import into PrairieLearn, there is a convenient way to do that. For details, visit the official documentation on Importing content from other platforms.

Adding a Standard Notes Page to Your Assessment

PrairieLearn enables you to add files to an assessment that students will be allowed to access. This could be a reference / formula / “cheat” sheet, for example.

Uploading the Reference Sheet

Suppose you have a reference.pdf file you want students to be able to access during the exam. First, we need to provide the file to PrairieLearn:

  • In the left sidebar, choose “Assessments” and click on the assessment you want to add the file to.
  • Click on the “Files” tab and hit the “Add new client files” button.
  • Upload your reference.pdf file via the file dialog that appears.
  • In the “Files” window, you should now see a new folder named “clientFilesAssessment”. If you click on that folder, you should see the reference.pdf file inside. You can click on it to verify that it’s the correct file.

Adding a Link to the Reference Sheet in the Assessment

Next, we need to give students access to the file in the assessment itself:

  • Still in the “Files” tab for the assessment, click the edit button for the file infoAssessment.json to open it in an in-browser editor.

  • We need to add one entry to the file: a "text" field containing a link to the file and any accompanying text we want. The "text" field must be valid HTML, and the file accessed via the URL {{ client_files_assessment }}/reference.pdf (or adjust for your file name). The {{ client_files_assessment }} is a placeholder that PrairieLearn will replace with the correct URL for the assessment’s files. For example:

    • Suppose you want your “Quiz 1” assessment to allow access to a reference.pdf file you’ve created.
    • When you open infoAssessment.json, you’ll see something like this:
    {
"uuid": "some unique identifier here",
"type": "Exam",
"title": "Quiz 1",
"set": "Quizzes",
... (more settings omitted for brevity) ...
}

    Add a new line for the “text” field. Anywhere is fine. For example, see below:

    {
"uuid": "some unique identifier here",
"type": "Exam",
"title": "Quiz 1",
"text": "<p><a href=\"{{ client_files_assessment }}/reference.pdf\">Click here for the exam reference sheet</a>. You may find it convenient to open this document in a new browser tab.</p>",
"set": "Quizzes",
... (more settings omitted for brevity) ...
}

    Note the HTML syntax, the use of " and \", and the , at the end. Such syntax is required. The following is just that line, which you can easily copy by hovering your mouse over the box and clicking the clipboard icon in the upper-right corner:

    "text": "<p><a href=\"{{ client_files_assessment }}/reference.pdf\">Click here for the exam reference sheet</a>. You may find it convenient to open this document in a new browser tab.</p>",

  • You may need to adjust the file name if yours is not called reference.pdf, and you may also wish to change the wording.

  • Click the Save button when you are finished editing.

With the changes above, students will see a link to the reference.pdf file when they open the assessment. I recommend you test this out with the “Student view without access restrictions” option to verify that it works as needed.

Allowing Students to Add a Custom Notes Page to Your Assessment

Warning

This section is still in testing and should not be relied upon until this message is removed!

NoteAcknowledgment

Thank you to the University of California - San Diego, Triton Testing Center, for their documentation on this topic, which served as the basis for the documentation below.

In some cases, rather than preparing a reference sheet yourself, you may want students to prepare their own respective reference sheets. However, please note: in the ETF, for reasons of exam security (especially when multiple courses’ exams are administered simultaneously), students are never allowed to bring in physical copies of their own reference sheets. Thus, if you want students to be able to use their own personally-prepared reference sheets during an exam, we need to set up PrairieLearn to allow this. The basic procedure is summarized below:

  1. Make a file upload question, allowing students to upload their reference sheet.
  2. Make a special upload assessment (a homework assessment configured in a special way) that contains the file upload question. The assessment should close days before the exam window starts.
  3. Configure PrairieLearn to allow each student access to their uploaded sheet during the exam.
  4. When the special upload assessment closes, review the uploaded sheets to ensure they follow any course requirements.
  5. Students can then take the exam with their respective uploaded files.

Details are provided in the following subsections.

Making a File Upload Question

  • Click on “Questions” in the left sidebar, and choose “Add questions” -> “Create new question” (not “Generate question with AI”).

  • Give a title and QID, such as “Reference Sheet Upload” and “ref-sheet-upload”.

  • With “PrairieLearn template” selected, choose the “File Upload” option.

  • Click “Create question”.

  • You will see the “Preview” tab for the question. Click on “Files”, and then the “Edit” button for question.html. Replace the entirety of its contents with the following (or adjust the wording / policies as needed):

    <pl-question-panel>
    <p> $\textbf{Instructions:}$</p>
    <p>Take a picture of your 1 page of handwritten notes. Save your notes in a file named: <b>personalnotes.png</b> </p>
    <p>Upload or drag your <b>personalnotes.png</b> file into the submission box. Click save and click show preview to view your notes in the submission panel. </p>
    <p><b> Submit your notes file here: </b> 
       <pl-file-upload file-names="personalnotes.png"> </pl-file-upload> 
    </p>
</pl-question-panel>
<pl-submission-panel>
    <pl-file-preview></pl-file-preview>
</pl-submission-panel>

  • Click “Save”.

Tip

For additional exams in the course, you may reuse the same file upload question you’ve created here, if you wish.

Making a File Upload Homework Assessment

Note

Before you can complete the steps below, you will need to (1) create the PrairieLearn assessment corresponding to your exam (though it need not be in its final form), and (2) obtain a PrairieTest exam UUID for your exam. Note that the PrairieTest exam UUID is different from the PrairieLearn assessment UUID. For details on where to get the PrairieTest exam UUID, see the ETF website.

  • Make the assessment:
    • Click on “Assessments” in the left sidebar, and choose “Add assessment”.
    • Give a title and short name that are reflective of the exam. For example, if this is for your Exam #1, you might use “Reference Sheet Upload for Exam 1” and “ref-sheet-upload-exam1”.
    • Set the type to “Homework” and the set to whatever you’d like.
    • You’ll now be on the “Questions” tab. Click “Add questions” and add the file upload question from the previous step. Press the blue disk icon button to save.
  • Disable personal notes:

    • Go to the “Settings” tab. In the “Student options” section, uncheck the box for “Allow personal notes”.

      Warning

      It is very important that “Allow personal notes” is unchecked and that you save this change. If the box is instead checked, students would be able to add other information to the homework assessment (and access it during the exam) that you would not be able to see.

    • Click “Save” at the bottom of the page.

  • Configure the assessment’s worth:
    • The file upload assessment can be worth 0 or more points. You might choose a non-zero worth if you want to penalize students for uploading a disallowed file. Alternatively, you could simply delete any disallowed files after reviewing them, and not assign any points to the assessment.
    • In any case, go to the “Questions” tab for the file upload assessment, and click “Edit” for the file upload question. In the right panel, set “Manual points” to whatever you wish.
    • Click the disk icon button to save.
  • Configure the assessment’s access:

    • Go to the “Access” tab. Click the “Edit” button.

    • Put a check in the “Date control” checkbox. Either let the file upload task be “Released” immediately, or choose “Scheduled for release” and set the date/time accordingly.

    • Select “Due on date” and pick a date/time sometime before the exam window starts. This will (1) give you / course staff time to review the uploaded sheets, and (2) prevent students from uploading new sheets after they are reviewed.

    • In the “Integrations” section a bit further down, check the box next to “PrairieTest”, and enter the Exam UUID from PrairieTest for your exam. (Thus, both your actual exam assessment and this file upload assessment will be linked to the same PrairieTest exam.)

    • In the “After completion” section, under “Question visibility after completion”, select “Show questions after completion”.

      Note

      You will be warned that this is an unusual setting for PrairieTest exams, but for the file upload assessment, you may safely ignore this warning.

    • Click “Save” at the bottom of the page.

Let’s verify that the assessment is configured correctly. Go to “Files”, and click “Edit” for infoAssessment.json. You should see something like the following:

{
  "uuid": "PRAIRIELEARN-ASSESSMENT-UUID",
  "type": "Homework",
  "title": "Any title, like Reference Sheet Upload for Exam 1",
  "set": "Any set name here",
  "number": "ANY-NUMBER",
  "accessControl": [
    {
      "dateControl": {
        "release": { "date": "RELEASE-DATE-TIME" },
        "due": { "date": "DUE-DATE-TIME (days before the exam window begins)" }
      },
      "integrations": {
        "prairieTest": { "exams": [{ "examUuid": "PRAIRIETEST-EXAM-UUID" }] }
      },
      "afterComplete": { "questions": { "hidden": false } }
    }
  ],
  "zones": [{ "questions": [{ "id": "FILE-UPLOAD-QUESTION-QID", "manualPoints": NUMBER-OF-MANUAL-POINTS }] }],
  "allowPersonalNotes": false
}

If anything in infoAssessment.json does not match the above (with your choices filled in), go back and check the settings and/or edit the json by hand.

Warning

Recall that the PrairieTest exam UUID (“PRAIRIETEST-EXAM-UUID”) is different from the PrairieLearn assessment UUID (“PRAIRIELEARN-ASSESSMENT-UUID”). Be sure you have the correct PrairieTest exam UUID in the infoAssessment.json file. Visit the ETF website for details.

Tip

For additional exams in the course, you may not reuse the file upload assessment you’ve created here. Each exam needs a different file upload assessment.

Reviewing Uploaded Sheets

After the file upload assessment closes (“DUE-DATE-TIME” in the example above), the students’ uploads may need to be manually reviewed to ensure they follow course policies (e.g., handwritten, one page, etc.). Follow these steps:

  • Click on “Assessments” in the left sidebar, and click on the file upload assessment you created for the exam.

  • Click on the “Manual grading” tab, and click on the question (e.g., “Reference Sheet Upload”).

  • Click on each instance to view the submission. You can assign points in the “Manual Points” field on the right, provide feedback if desired, and click “Grade”.

  • You also have the option of deleting a student’s upload if it does not meet course requirements. To do this, click the “Delete” button in the top-right of where the uploaded file is displayed when grading manually.

    Warning

    Students will not be automatically notified if their upload is deleted. Thus, you may wish to notify affected students.

With the above steps complete, students will be able to access their uploaded reference sheets during the exam, and you will have ensured that they follow course policies.
