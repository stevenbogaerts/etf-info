This is a quick-start guide for faculty members at University of Michigan - Ann Arbor on using PrairieLearn.

Note

Given the large range of faculty member backgrounds in the concepts discussed here, this documentation does not attempt to be one-size-fits-all nor comprehensive. Rather, this is provided to point faculty members to a few key ideas to get started quickly. The official PrairieLearn documentation, web searches, and AI questions are all good resources for more information. I (as the ETF faculty advisor) am also happy to assist U-M faculty members on these topics.

This page provides brief information on PrairieLearn, PrairieTest, and how to get access to PrairieLearn.

What is PrairieLearn?

PrairieLearn is an online learning and assessment platform useful for practice, homework, quizzes, and exams. Some notable features include:

  • Great flexibility in question types and randomization of question details
  • Support for automatic and manual grading
  • Easy-to-use web interface, plus the opportunity to integrate with agentic AI workflows

Giving an Exam with PrairieLearn

You can use PrairieLearn independently for homework, practice, and exams you administer yourself. For example, you might:

  • Have students bring a laptop (not locked down) to class and use PrairieLearn for an assessment
  • Have students use any computer lab desktop (not locked down) to take an assessment

The assessment could be available only within a strict time window (e.g., during a class period) or could be available longer as a take-home exam.

Of course, the above options vary in terms of exam security and environmental control. At U-M Ann Arbor, if you wish to give exams in a more tightly-controlled environment, you’ll need the Engineering Testing Facility (ETF). The ETF uses PrairieTest to administer exams, which integrates with your PrairieLearn content.

Note

This Quick-Start Guide is about PrairieLearn, not about PrairieTest nor the ETF. For more information on those resources, visit the ETF website.

How Much Work Is It to Prepare PrairieLearn Materials?

This varies widely, of course. Some things to consider:

  • Converting Canvas questions: If you already have questions in Canvas, there is a handy Canvas import tool that can help a lot. You will still need to verify each question, though.
  • Using AI: You can save tremendous amounts of time by using AI with the repository interface. I strongly recommend working through this entire Quick-Start Guide and taking the time to be comfortable with this workflow.
  • Using existing text questions: You may already have a lot of questions in a text format (e.g., .txt, .tex, or even structured formats like .docx). You could convert them one at a time by pasting into the web interface’s AI question generator, or convert in larger sets via AI and the repository interface (highly recommended).
  • Considering question complexity: Time needed depends on how complex your questions are. Questions with helpful randomization take longer to create and fully verify.
  • Creating exams: If you’re planning to give exams in the ETF, then your first time creating exams will likely take longer than you are accustomed to. This is because an asynchronous exam should ideally have a large enough question pool that exam content does not easily leak out.

Depending on how much time you have before you need the content, you may want to start with a smaller pilot (e.g., a single homework assignment, or a couple homework assignments and one quiz). To create an entire course worth of PrairieLearn content can take at a bare minimum a couple dozen hours from existing simple content, up to hundreds of hours for all new and/or highly complex content. Once your content is built, it is highly reusable, with modest incremental cost for any further development, and can serve as a great resource for your students for years to come!

Getting Access to PrairieLearn and the U-M ETF

  • Request a PrairieLearn course: For each course you intend to use with PrairieLearn, you need a “PrairieLearn course” to be created for you, if you don’t already have one. Go to the PrairieLearn site and click “Free sign up” in the top-right corner. Login by clicking the “University of Michigan” button down below, not via “Sign in with Google”. Follow the steps presented to request your course.
  • Get in touch with the ETF Staff: If you wish to use the ETF for exams, be certain to reach out to the ETF staff if you haven’t already.
  • Get a GitHub.com account: GitHub is a web-based platform for managing software development projects. Eventually, it will play an integral role in your PrairieLearn workflow. If you don’t already have an account, go to GitHub.com and click the “Sign up” button in the top-right corner. Follow the steps presented to create your account.
  • Access Your GitHub PrairieLearn Repository: When your PrairieLearn course is created, you will receive an email with an invitation to access your course’s GitHub repository (a collection of files related to your PrairieLearn course). Accept the invitation and connect it to your GitHub account.
